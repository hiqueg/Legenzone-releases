# Legenzone — Downloads

Aplicativo para corrigir as legendas auto-caption do CapCut.

## Baixar

1. Vá em **[Releases](../../releases/latest)**.
2. Baixe o **`Legenzone.exe`** da versão mais recente.
3. Dê duplo-clique para abrir (não precisa instalar nada).

> Na primeira vez, o Windows pode mostrar um aviso azul ("Windows protegeu seu PC").
> Clique em **Mais informações → Executar assim mesmo**.

## Atualizações

O app avisa sozinho quando há uma versão nova (faixa no topo) e atualiza em 1 clique.
