# Legenzone — Downloads

Aplicativo para corrigir as legendas auto-caption do CapCut.

## Como instalar

1. Vá em **[Releases](../../releases/latest)**.
2. Baixe o **`Legenzone.zip`** (em *Assets*).
3. **Clique com o botão direito no ZIP → Extrair tudo** (escolha, por exemplo, a Área de Trabalho).
4. Abra a pasta **`Legenzone`** e dê duplo-clique em **`Legenzone.exe`**.

> 💡 Dica: dentro da pasta, clique com o botão direito em `Legenzone.exe` →
> **Enviar para → Área de trabalho (criar atalho)** para abrir fácil depois.

> Se o Windows mostrar **"Windows protegeu seu PC"**, clique em
> **Mais informações → Executar assim mesmo** (é um aviso padrão para apps sem assinatura paga).

## Atualizações

O app avisa sozinho quando há versão nova (faixa no topo) e atualiza em 1 clique.
